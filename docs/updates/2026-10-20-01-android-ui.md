## 用户需求

先将项目纳入本地 Git 并上传 GitHub 公开库；参考 GitHub 项目，重点修复 APK 首页开始学习与美文精读的显示和交互问题。用户报告手机为 iQOO Neo9，Android 12 / 橘子 6，允许在需要时更新电脑模拟器。

## 完成内容

1. 初始化 Git 并提交修改前基线，创建并推送公开仓库；签名、私人备份、原始图片和构建缓存未公开。
2. 手机首页将学习任务置于统计前，开始按钮首屏可见；修复长词书名把标题挤成逐字换行。
3. 为学习补齐上一张、跳过、保存评价并下一张，沿用原有完整评分撤销；修复最后一张总结与动态拼写评分事件绑定。
4. 精读按跳转栈挂载事件，修复从首页进入后点词和辅助切换不生效。增加手机底部释义抽屉、字号、阅读位置恢复、导入草稿保留；收纳统计与次要来源，正文优先。
5. 原生返回键复用网页路由栈，底部导航随 WebView 可见区域布局，避让系统栏和软键盘；停止/离开阅读时取消后续朗读计时任务。
6. 用原签名生成正式 `1.1.1-local.3` APK，递增版本码至 3，成功覆盖安装并验证文章、词书和学习进度保留。重启电脑本地服务，使 HTML 修改生效。
