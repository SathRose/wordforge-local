## 问题与改动

### 首页与学习

- 窄屏原本把四张统计卡纵向排开，“开始学习”落到首屏之外；改为学习任务优先、统计两列排列。
- 顶部标题被长词书名挤成逐字换行；标题保持单行，词书名截断，完整名称仍可在换书面板查看。
- 原学习流依赖 Enter 或未被发现的滑动手势才能提交下一题；新增“上一张 / 跳过这词 / 保存评价并下一张”。选择题点击后直接按对错保存并推进，卡片题仍在确认下一张时提交；返回上一张沿用原有完整撤销逻辑。
- 修复最后一张提交后没有即时显示总结、总结按钮未绑定的问题；拼写题与例句填空输入题已移除。
- 底部导航改为应用内部的布局元素，不再脱离 WebView 边界定位。Android 原生统一处理系统栏、刘海和软键盘的 Insets。
- 快速连续反馈只展示最新一条，避免多个提示遮住阅读正文。

### 美文精读

- 修复从首页文章卡进入时只有内容、没有绑定点词/辅助/练习等事件的问题。精读挂载按跳转栈判断，不再只看一级导航。
- 首屏提供继续阅读与离线导入；常用新闻栏目在前，其余来源、主题搜索与网络诊断可展开，未删除原有来源。
- 词汇画像收纳为详情，正文前仅保留主要阅读辅助；增加字号调整和按需展开的朗读控制。
- 点词释义在手机上用底部抽屉显示，正文位置不变；加入生词本和完整词条保留。
- 保存阅读位置；从完整词条返回、重新打开文章时恢复位置。粘贴草稿切换页签后不丢失。
- 原生返回键复用应用已有的路由栈，而不是跳过文章直接回首页。
- “停止朗读”、离开页面或切到后台会同时取消后续分段计时任务。

## 如何回归

零依赖逻辑检查见主 README。可选浏览器检查需要外部安装的 Playwright（本应用运行不依赖它）：

```sh
node checks/test-mobile-ui.cjs
```

可设置 `PLAYWRIGHT_MODULE` 为已有模块的绝对路径、`CHROME_PATH` 为 Chrome 可执行文件路径。
覆盖 320×640、360×640、390×844、412×892、458×966、800×360 横屏及 1440×900 桌面；检查首屏按钮、触控推进与撤销、总结、选择题自动推进、精读辅助、点词弹层、位置恢复、导入和横向溢出。

原生检查**只用于隔离的测试模拟器，不要对含真实学习记录的手机执行**：

```sh
node android/build-apk.cjs --qa
adb -s emulator-5556 install -r android/build-qa/wordforge-qa.apk
adb -s emulator-5556 shell am start -n com.wordforge.local/.MainActivity
node checks/test-android-ui.cjs
```

可通过 `WORDFORGE_DEVICE` 指定另一模拟器。覆盖真实触控、原生返回键、软键盘弹出后的可见区域和 WebView 重载后的持久化。

## 兼容性边界

- 仍支持 Android 8.0+，Android 12 位于支持范围内，不使用高于 API 30 的新调用。
- 原生验证使用 API 36 与 API 31 AOSP 模拟器；均不等同于 iQOO Neo9 / OriginOS 真机验收。API 31 的 WebView CDP 触摸/截图不可用，测试以 DOM click 回退并跳过 IME 打开断言。
- 曾尝试补装 API 31 / Android 12 系统镜像，但下载未得到完整有效的 ZIP，未完成该版本模拟器验收。现有 API 34/36 镜像不需要升级，未替换或清空原有模拟器数据。
- 阅读来源的可达性与 UI 修复分开：检查使用隔离测试文本，不宣称所有新闻源在所有手机网络都能连接。
- 更新使用同包名、同签名、递增 versionCode。不要通过卸载旧版来更新；先导出备份再覆盖安装。
