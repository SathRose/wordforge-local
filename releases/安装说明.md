# 词匠 · 安卓本地版

安装文件：**词匠-本地版-1.1.1-local.2.apk**，约 4.47 MiB（4.69 MB）。

1. 将 APK 发送到安卓手机，在手机的文件管理器中打开。
2. 如果系统询问安装来源权限，允许本次所用的文件管理器/浏览器安装此 APK，安装完成后可关闭此权限。
3. 支持 Android 8.0 及以上，无需连接电脑即可使用内置词库。

## 本版内容

- 读写教程：Part 1（第7–9页）、Part 2（第20–22页）。
- 词达人：CET4（第二版）List 01–10，已补充释义及学习资料。
- 学习 → 换词书：自定义词书默认在最前面。
- 选择词书 → 调整顺序：置顶、上移、下移、恢复默认，点击“保存顺序”后生效。
- 词表导入、完整备份导出/恢复、系统英语朗读。

## 学习记录

- APK 不包含电脑浏览器的个人学习进度，不会自动同步电脑记录。
- 迁移记录：在电脑网页版“更多 → 设置 → 数据”选择“导出全部数据”，将 JSON 文件发送到手机，再在手机的“更多 → 设置 → 数据 → 导入备份”中选择该文件。
- 导入完整备份会替换手机当前数据。手机已有进度时，先导出手机端完整备份再操作。
- 不要卸载应用或清除应用数据，否则会删除手机上的学习记录。同包名、同签名 APK 的覆盖更新可保留数据，更新前仍建议导出备份。
- 安装包使用本地独立包名及签名，不会覆盖上游官方应用的数据。

发音需要手机安装英语文字转语音（TTS）语音包；没有语音包时，普通背词仍可使用。

已在 Android 14 模拟器验证安装、排序保存、进度持久化、备份导出和恢复；未在你的实体手机上测试。
